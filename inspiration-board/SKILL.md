# 选题灵感工作台

把一个对标账号拆成两类可复用资产：
1. **可点击的视频灵感台**（HTML，直接跳原片）
2. **句式对版表**（左：对标原句；右：用户照着这个句式能说的话）

## 核心原则（踩过的坑，必须遵守）

1. **用他的句式，不是他的主题。** 不要"模仿他的风格"，要直接复刻他的句子结构（"X 是 X 最 Y 的功能，没有之一"、"我比 X 早 X 年"、"所有 X 记住一句话"），把内容换成用户自己的。
2. **只晒用户自己的事。** 不要把对标账号 PPT 里的行业案例、第三方故事，当成用户的学员案例。用户能晒的只有：他自己的数据、他自己的产品、他自己的经历、他自己的客户。
3. **短视频钩子，不是公众号标题。** 钩子要短、冲、下判断、有数字、有对比、带命令；不要"XX 是什么"、"为什么"、"如何"这种咨询腔。
4. **先对版，再写稿。** 第一步先给句式对版表让用户挑，用户确认哪几条"像我会说的话"，再往下写逐字稿。不要一上来就写 60 秒稿子。
5. **不要 AI 味。** 避免排比、对仗、金句堆砌、"赋能/抓手/闭环"这类词。真人说话有废话、有停顿、有"我跟你说"、有具体的人。

## 工作流

### 第 1 步：确认对标账号

- 用户给账号名时，先用 `general_search` 搜"账号名 + 平台 + 关键词"，确认账号主体（同名很多）、平台、账号 ID、定位简介。
- 如果搜出来多个同名账号，把候选列给用户确认，不要猜。
- 搜 10-15 条该账号的代表性视频公开链接（抖音 `iesdouyin.com/share/video/...` 这类可直接点开的链接）。

### 第 2 步：按 5 个方向分类

把搜到的视频按这 5 类归堆（不是所有账号都 5 类齐全，缺哪类就空着）：

| 方向 | 内容特征 | 适合谁用 |
|---|---|---|
| 1. 认知升维 | 重新定义一个大词、反常识判断、行业趋势 | 想立"思想领袖"人设 |
| 2. 做 IP / 个人品牌方法论 | 晒自己公司怎么做内容、怎么做分层 | 教别人做内容/IP |
| 3. 组织 / 一人公司 AI 化 | 全员配工具、蒸馏员工、组织重构 | 面向企业主或个体从业者 |
| 4. 变现 / 赚钱逻辑 | 学员结果、案例拆解、反常识开场 | 卖课/接咨询/高客单 |
| 5. 落地实操 / 见证 | 真实客户、现场演示、工作台录屏 | 做培训/陪跑/交付 |

每条视频标注：标题、一句话内容、**钩子类型**（反常识金句/晒数字/自曝/蹭权威/学员证言/命令句……）、跳转链接。

### 第 3 步：生成灵感台 HTML

- 用 `assets/inspiration-board.html` 模板。
- 在 `<main>` 里按 5 个方向填 section，每个方向一组卡片。
- 每张卡片就是一个 `<a>`，href 直接填抖音/小红书原片链接，target="_blank"。
- 头部放账号名、平台 ID、定位标签、主页链接。
- 跑 `html` skill 的 `scripts/shot.py` 自检，确认渲染没问题。
- 用 `present_files` 交付 HTML。

### 第 4 步：问用户定位

灵感台交付后，问用户三件事：
1. 你是干嘛的（行业、产品、服务谁）
2. 你有什么真实数据（粉丝量、成交、学员数、年限）
3. 你想让视频带来什么（涨粉/卖课/接咨询/带货）

如果用户已经主动说过，跳过。

### 第 5 步：出句式对版表（核心交付）

- 从第 2 步的视频里挑出**钩子最冲、最有辨识度的 8-12 条原句**。
- 做成两列表格：
  - 左列：对标账号的原句（直接引用他视频里的标题/金句）
  - 右列：用户照着这个句式、套自己的事能说的版本
- 右列必须只用用户**自己的真实素材**（他的数据、产品、经历），不能编学员案例、不能套对标账号的行业案例。
- 表后让用户挑"哪几条像我会说的话"。

详细方法见 `references/pattern-matching.md`。

### 第 6 步：用户挑完后写逐字稿

- 用户挑 1-3 条后，每条写 60 秒口播稿（180-220 字）。
- 语气要求：见 `references/hook-taxonomy.md` 的"去 AI 味"清单。
- 写完让用户念，标出"不像我会说的"，继续调。
