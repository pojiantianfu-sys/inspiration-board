# 选题灵感工作台

把一个对标账号拆成两类可复用资产：
1. **可点击的灵感台**（HTML，直接跳原片/原笔记）
2. **句式对版表**（左：对标原句；右：用户照着这个句式能说的话）

## 核心原则（踩过的坑，必须遵守）

1. **用他的句式，不是他的主题。** 不要"模仿他的风格"，要直接复刻他的句子结构，把内容换成用户自己的。
2. **只晒用户自己的事。** 不要把对标账号 PPT 里的行业案例、第三方故事，当成用户的学员案例。
3. **平台决定风格。** 抖音是口播钩子（短、冲、下判断）；小红书是情绪型/反常识型/身份代入型标题（"被XX震撼到"、"劝你别XX"、"i人怎么XX"）。不要把抖音的干货体搬到小红书，也不要把小红书的情绪标题搬到抖音。
4. **时效性是硬门槛。** 小红书爆款生命周期只有1-2周，超过1个月的选题写了也不爆。只看最近30天内的内容。
5. **数据门槛。** 只参考百赞以上的笔记/视频。几十赞的没有参考价值。
6. **洗稿=原句式一个字不改。** 除了人群词，其他字一个都不动。改了就不是爆款句式了。
7. **"AI重讲"法。** 如果用户的差异化是"AI+某个赛道"（比如AI+知识IP、AI+高客单），就把对标账号的原选题前面加"AI"，或者把人群换成"咨询师/知识IP"。
8. **不要 AI 味。** 避免排比、对仗、金句堆砌、"赋能/抓手/闭环"这类词。

## 工作流

### 第 0 步：确认平台和对标账号

先问用户两件事：
1. 你主要在哪个平台发？抖音还是小红书？
2. 你有没有想对标的账号？

- **有对标账号**：直接走第0.5步（小红书）或第1步（抖音）
- **没有对标账号**：走第0.3步，先帮她找

### 第 0.3 步：如果用户没有对标账号，先帮她找

**目的**：通过关键词搜索，找到同赛道、同客单价、同平台的爆款账号。

**操作**：
1. 先问清楚用户的定位：赛道是什么？客单价多少？主要服务谁？
2. 用2-3个关键词在目标平台搜（比如"高客单 知识IP"、"AI 一人公司"、"咨询师 赚钱"）
3. 按"最多点赞"排序，看前20条爆款笔记/视频
4. 统计这些爆款是谁发的，出现频率最高的3-5个博主就是最值得对标的
5. 把这3-5个博主列给用户，让她挑1-2个最对味的

**注意**：
- 不要只看粉丝量，要看最近30天的赞数——有些小号最近爆了，比大号更值得对标
- 如果某个博主在这个平台赞数很低（说明主战场不在这），直接跳过
- 推荐时简单说一句每个博主的特点（比如"鲁细细：21万粉，专做知识IP变现"）

**筛选标准**：
- 最近30天有百赞以上的爆款
- 内容方向和用户的赛道/客单价匹配
- 平台一致（不要拿抖音大V对小红书）

### 第 0.5 步：小红书实战流程（如果用户主战场是小红书）

**不要搜泛关键词**（"高客单知识IP"这种搜出来的内容太泛），直接搜用户给的对标博主名字。

用 `mac_computer_use_tool`（plane="bu"）上小红书：

```python
import seed_browser_use as bu
bu.navigate("https://www.xiaohongshu.com/search_result?keyword=博主名字&type=51")
bu.wait_for_load()
bu.scroll(500, 400, "down", amount=2)
bu.wait_for_load(timeout=3)

# 抓取所有笔记：标题、链接、博主、日期、赞数
js_code = """
const items = document.querySelectorAll('section.note-item');
const results = [];
items.forEach(item => {
    const linkEl = item.querySelector('a.cover');
    const authorEl = item.querySelector('a.author');
    const likeEl = item.querySelector('.like-wrapper .count');
    results.push({
        link: linkEl ? linkEl.href : '',
        author: authorEl ? authorEl.textContent.trim() : '',
        likes: likeEl ? likeEl.textContent.trim() : ''
    });
});
return JSON.stringify(results, null, 2);
"""
print(bu.js(js_code))
```

**筛选规则：**
- 只保留最近30天内发布的
- 只保留百赞以上的
- 给用户列成表格：标题、博主、日期、赞数、可点击链接
- 让用户自己点链接看原文，挑"哪个句式能洗"

### 第 1 步：确认对标账号（抖音/通用）

- 用户给账号名时，先用 `general_search` 搜"账号名 + 平台 + 关键词"，确认账号主体、平台、定位简介。
- 搜 10-15 条该账号的代表性视频公开链接。

### 第 2 步：按方向分类

把搜到的内容按方向归堆：

| 方向 | 内容特征 |
|---|---|
| 认知升维 | 反常识判断、行业趋势、重新定义大词 |
| 做IP方法论 | 怎么做内容、怎么做分层、怎么涨粉 |
| 组织/一人公司 | 配工具、蒸馏员工、组织重构 |
| 变现/赚钱逻辑 | 学员结果、案例拆解、高客单打法 |
| 落地实操/见证 | 真实客户、现场演示、工作台录屏 |

每条标注：标题、一句话内容、钩子类型、跳转链接。

### 第 3 步：生成灵感台 HTML

**小红书平台**：用 `assets/xiaohongshu-idea-board.html` 模板。
- 按**内容方向**分类（不是按博主），5个方向：
  1. 反常识认知（"越拍自己越火不了"）
  2. 做IP方法论（"如何做一个以赚钱为目的的账号"）
  3. 高客单成交（"如何吸引高端客户看一眼就买"）
  4. AI+商业（"我把AI工具免费公开为什么更赚钱"）
  5. 搞钱变现（"博主赚钱有4个层次"）
- 每条卡片必须有：
  - 标题（原标题，不改字）
  - 一句话提炼（这个钩子为什么能爆）
  - 钩子类型标签（反常识否定/数字+结果/自曝结果/秘密感/情绪冲击……）
  - 可点链接（直接跳原笔记）
  - 赞数标注
- 不要按博主分类，用户不关心是谁发的，关心的是选题方向。

**抖音/通用平台**：用 `assets/inspiration-board.html` 模板。
- 按5个方向分类：认知升维/做IP方法论/组织一人公司/变现逻辑/落地实操。

**通用要求**：
- 每张卡片就是一个 `<a>`，href 直接填原片/原笔记链接，target="_blank"。
- 跑 `html` skill 的 `scripts/shot.py` 自检。
- 用 `present_files` 交付 HTML。

### 第 4 步：问用户定位

1. 你是干嘛的（行业、产品、服务谁）
2. 你有什么真实数据（粉丝量、成交、学员数、年限）
3. 你想让视频带来什么（涨粉/卖课/接咨询）

### 第 5 步：出句式对版表（核心交付）

- 挑出钩子最冲、最有辨识度的 8-12 条原句。
- 两列表格：左列原句，右列用户版本。
- 右列只用用户自己的真实素材，不能编。
- 如果用户的差异化是"AI+赛道"，用"AI重讲"法：原句式前面加"AI"，或把人群换成用户的受众。

详细方法见 `references/pattern-matching.md`。

### 第 6 步：用户挑完后写逐字稿

- 用户挑 1-3 条后，每条写完整内容（抖音60秒口播 / 小红书图文笔记）。
- 写完让用户念/看，标出"不像我会说的"，继续调。

## 小红书爆款标题类型（参考）

| 类型 | 公式 | 例子 |
|---|---|---|
| 情绪冲击 | "被[价格][人群]的思路深深震撼到" | 被29800疗愈师的思路深深震撼到 |
| 反常识/否定 | "劝你别XX" / "千万别XX" | 劝你别做高客单IP，除非你想清楚这3件事 |
| 身份代入 | "[身份标签]怎么[做某事]" | i人咨询师怎么接高客单？ |
| 数字结果 | "[时间]做到[数字]，我做对了什么" | 1万粉成交8位数，我到底做对了什么 |
| 对比反差 | "同样[事]，为什么[她]3倍" | 同样做咨询，为什么她1个月顶你半年 |
| 踩坑血泪 | "踩过[数量]个坑后总结的" | 陪跑1000个咨询师后，穷的都有同一个毛病 |

详细方法见 `references/hook-taxonomy.md`。
